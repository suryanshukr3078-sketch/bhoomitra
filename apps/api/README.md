# Land Governance Platform API

FastAPI-powered RESTful API and GIS spatial service for the Land Governance & Cadastral Administration Platform.

## Quick Commands
- `uv sync`: Install dependencies into virtual environment
- `uv run alembic upgrade head`: Apply database schema migrations
- `uv run uvicorn app.main:app --reload --port 8000`: Run local development server

Interactive Swagger docs: `http://localhost:8000/docs`
